# ADR-007：ARR 外推从最近披露值出发（水平校准）

> 状态：已决策 2026-11-22

## 背景

今日估算原先取「全历史拟合曲线在今天的值」。曲线在最后一个锚点处常有 10% 以上残差：
补上 Anthropic 10-31 的 81B 后，曲线在该点给出 93B，今日估算 108B——残差被原样带进大数字。
更早的问题是锚点 114 天没更新，纯外推把 Anthropic 抬到 154B。

## 决定

外推段与今日值乘以校准系数（披露值 ÷ 曲线在该点的值，`fit.level_shift_ratio`），即从最近
披露值出发，增速仍用拟合的瞬时增速。图上虚线从锚点本身起笔。页面常驻「距最近披露 N 天」
（>45 天提示、>90 天标红）与估算可信度；每日更新任务每天搜新披露（daily-routine.md）。

## 后果

+ 刚披露完的那几天，大数字贴着披露值走，不再比刚披露的数字高出一截。
− 拟合实线与外推虚线在最后锚点处不再连续（残差直接可见，这是有意的）。
− 增速仍是全历史加权拟合值（Anthropic 21.8%/月，高于近三个月实际的约 8%/月），久不更新
  锚点时仍会高估——靠锚点年龄提示和每日搜索兜住，不靠调参。
