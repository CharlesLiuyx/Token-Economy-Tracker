# ADR-006：报告式外壳；条形图与表格改原生 DOM，Chart.js 只留时序图

> 状态：已决策 2026-11-22（修订 ADR-001 中「图表全部走 Chart.js」的部分）

## 背景

卡片式仪表盘信息密度低：GPU 5 张卡片扩到 16 个卡型后放不下；条形图画在 canvas 里文字
不能选中 / 搜索，也没法在同一行并排「较 7 天前」；原生 title 提示延迟约 1 秒且不可样式化。

## 决定

外壳改成报告式（24px 顶栏、左侧章节 / 资产目录、无圆角无动效、三档宽度与字号、术语 hover
释义、全站单例悬停提示）。条形图（Top Models / Vercel 份额 / SDK）与全部表格用原生
HTML + CSS；Chart.js 只负责折线类时序图（对数轴、置信带、图例聚光用它更省事）。

## 后果

+ GPU 16 卡型一张表看完（分位区间条、每 GB 单价、7 / 30 天变化、迷你柱）；表头吸顶、可排序。
+ 条形图文本可选中，行内直接带变化量；页面体积 gzip 144KB。
− app.js 从 265 行增到约 600 行，外壳逻辑（目录、跳转栈、提示、术语标注）需要自己维护；
  约定全部写在 frontend.md。
